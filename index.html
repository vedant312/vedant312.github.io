About

A maker who sweats the data.

I'm a full-stack software engineer with 2+ years of experience building production systems where the data is the hard part. At Owlbyte I work across the stack on Dopamyn — an AI-powered growth and outreach platform for X (Twitter) — shipping features from the database schema and backend services all the way to the interface people click.

I like owning problems end to end: designing the API, wrangling the data pipeline, and building the UI on top. Lately that has meant a lot of agentic-AI work — from AI-drafted outreach to a Model Context Protocol connector that lets tools like Claude talk to our product. I move fast with Codex and Claude in the loop, without letting quality slip.
